# QR ページの公開範囲

物品詳細の「公開設定」→「QR ページ」で公開範囲と短い説明を変更します。新規登録時は非公開です。

QR コードには `/i/管理番号` の URL を使います。管理番号は `M-2026-000001` のように登録年を含み、管理画面の「QR コード用のリンク」で確認できます。編集・アーカイブ・復元でも管理番号は変わりません。

- 未ログインの人には、物品ごとの「QR ページを公開する」がオンの場合だけ基本情報を表示します。
- 表示するのは持ち主の表示名・品名・状態・QR 公開用の短い説明（300文字まで）です。管理メモ・収納先・中身・タグ・画像・所有関係は表示しません。
- 短い説明はプレーンテキストです。管理メモや uses の説明からは転記しません。公開中の品名・状態・短い説明の変更は、物品を保存すると反映されます。
- 新規・既存の物品とも初期値は非公開です。公開をオフにすると以降のアクセスでは情報を表示しません。アーカイブでも非公開になり、管理中へ戻しても自動で公開しません。
- 非公開・存在しない物品は、同じ案内と `404` を返します。ログインへ自動で転送しません。
- ログイン中の管理者が QR を開くと `/items/管理番号` の管理画面に移動します。「未ログイン時の表示を確認」では管理者も公開ページだけを確認できます。
- 公開ページの「管理者としてログイン」からは、ログイン後にその物品の管理画面へ戻ります。
- 紛失・拾得の報告は未実装です。ボタンは「準備中」と表示して無効にしています。

持ち主の表示名は本番の環境変数 `PUBLIC_OWNER_NAME` で指定します（初期値 `Ryoga`）。ローカルでは `.dev.vars` でも上書きできます。認証用の GitHub ID やプロフィール情報は公開しません。

QR の公開設定と uses API の公開設定は独立しています。QR を公開しても uses API には追加されず、uses を公開しても QR ページが公開されることはありません。

QR ページとそのデータ取得は `Cache-Control: private, no-store` を返し、検索エンジン向けに `noindex, nofollow` を指定します。画像の公開は uses API の画像設定に従います。
